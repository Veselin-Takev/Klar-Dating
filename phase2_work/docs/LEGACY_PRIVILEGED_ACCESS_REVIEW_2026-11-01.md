## Required cross-tenant negative matrix

For each endpoint and scheduled job, use at least one successful authorized own-tenant example **and** denial/zero-disclosure evidence for: foreign signed tenant, same-tenant foreign UID, copied profile label, missing/expired membership, stale claim, other tenant's object within a shared chat, admin-only operation from user role, replayed lease/job, child subtenant reading parent, and orphaned/blocked account. Firestore client Rules, Storage Rules and **Admin SDK** must be tested independently; Admin SDK bypasses client Rules.

For deletion tests, record pre- and post-state counts and cryptographic evidence for the correct tenant *and* the unaffected neighbor tenant, with no raw customer PII in Git. For photo purging, confirm actual Cloud Storage generation conditions and absence of a decision-change race, not only mocked policy helpers.
